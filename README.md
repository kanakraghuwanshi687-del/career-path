# 🧭 CareerPath – Career Roadmap Explorer

Front End Development Project (HTML, CSS, JavaScript).

## Features
- Browse careers by category (Software, Data & AI, Electronics, Security, Design)
- Live search across careers, skills and roles
- Step-by-step roadmap popup for each career
- Progress tracking saved in the browser (localStorage)
- Dark / light mode, fully responsive

## Run locally
Open `index.html` in a browser. No installation needed.
